# 🌟 OpinionFlow - 연수 강의용 실시간 의견수렴 & 한국어 텍스트마이닝 플랫폼

> **Mentimeter**나 **Slido**처럼 간편하고, 한국어 형태소 정제 엔진과 인터랙티브 시각화를 탑재한 무과금·초경량 웹 플랫폼입니다.  
> 별도의 유료 서버 없이 **GitHub Pages** 무료 정적 호스팅만으로 배포되며, **Firebase Realtime Database**를 연동하여 0.1초 내 초저지연 실시간 동기화를 지원합니다.

---

## 🎯 새로 업그레이드된 5대 핵심 기능

1. **🔄 세션 응답 초기화 기능 (테스트 데이터 원클릭 삭제)**
   - 강사 화면 상단의 **[🔄 (초기화)]** 버튼을 누르면, **등록해둔 질문 리스트와 방 코드는 그대로 유지**되면서 제출되었던 응답 결과만 깨끗이 '0명'으로 비워집니다.
   - 강연 전 리허설 및 테스트를 마음껏 해보고, 본 강의 시작 직전에 초기화하여 바로 진행할 수 있습니다.

2. **📂 세션 관리 및 다른 세션 열기**
   - 상단 세션 코드 배지 클릭 시 **세션 전환 모달**이 열립니다.
   - 기존에 진행했던 방 코드를 입력하여 이전 연수 결과를 다시 열람하거나, [새 세션 만들기]를 통해 새 강의를 즉시 개설할 수 있습니다.
   - 최근 방문했던 세션 목록이 자동 기록되어 원클릭으로 쉽게 이동할 수 있습니다.

3. **📊 선택형 투표 (객관식 Polling) 지원**
   - 질문 생성 시 **'주관식 서술형'**뿐만 아니라 **'선택형 투표'**를 선택할 수 있습니다.
   - 참여자는 터치 친화형 보기 카드 버튼을 눌러 손쉽게 투표합니다.
   - 강사 화면에서는 Mentimeter 스타일의 **실시간 애니메이션 가로 막대 차트 (득표율 %, 득표수, 1위 배지)**로 즉시 시각화됩니다.

4. **⏭️ 한 세션 내 다중 질문 순차 진행 (Multi-Question Flow)**
   - 한 세션에 질문을 1개뿐만 아니라 3개, 5개 등 원하는 만큼 미리 등록할 수 있습니다.
   - 참여자가 응답을 제출하면 **"제출 완료! 강사님이 다음 질문을 시작하면 자동으로 화면이 바뀝니다."** 대기 화면이 표시됩니다.
   - 강사가 대형 화면에서 **`[다음 질문 ▶]`**을 누르는 순간, **모든 참여자의 스마트폰 화면이 실시간으로 다음 질문 입력 화면으로 일제히 전환**됩니다!

5. **📋 세션별 질문 저장 및 관리 기능**
   - 상단의 **[질문 관리]** 버튼을 통해 언제든 질문 추가, 제목 수정, 유형 변경(주관식/선택형), 보기 항목 추가/삭제, 순서 이동이 가능합니다.
   - **[✨ 추천 질문 5종 자동 채우기]** 버튼을 누르면 연수 현장에서 가장 자주 쓰이는 검증된 질문 5종(주관식 3개 + 선택형 2개)이 원클릭으로 세팅됩니다.
   - 저장 시 Firebase에 영구 보관되므로 브라우저를 닫았다가 다시 열어도 질문이 그대로 유지됩니다.

## 📂 프로젝트 구조

```text
모두의 의견공유/
├── index.html              # 참여자(연수생) 모바일 화면 (주관식/선택형 폼, 자동 화면 전환, 폭죽)
├── presenter.html          # 강사용 프리젠테이션 대화면 (QR, 실시간 카운트, 질문 제어, 투표 차트, 워드클라우드)
├── assets/
│   ├── css/
│   │   └── custom.css      # 글래스모피즘, 바운스 카운터, 확대 모달, 형광펜 스타일
│   └── js/
│       ├── firebase-service.js # Firebase Realtime DB 연동, 다중 질문/세션 관리/초기화 모듈
│       ├── korean-nlp.js       # 한국어 최장일치 형태소/조사·어미 분리 및 역색인 엔진
│       ├── presenter-app.js    # 강사 프리젠테이션 제어 (투표 차트, 워드클라우드, 카드 줌, 세션 관리)
│       └── participant-app.js  # 참여자 폼 제어 및 실시간 질문 전환 감지
└── README.md
```

## 🚀 빠른 강의 진행 가이드 (강사 워크플로우)

1. **질문 사전 등록 (강의 전날 또는 직전)**:
   - `presenter.html`에 접속한 뒤 상단 **[질문 관리]**를 누릅니다.
   - [✨ 추천 질문 5종 자동 채우기]를 누르거나 본인의 강의 질문을 1번부터 5번까지 등록하고 [질문 저장 및 세션 적용]을 누릅니다.
2. **테스트 및 리허설**:
   - 새 탭에서 `index.html`을 열고 직접 주관식 의견 작성 및 객관식 투표를 테스트해봅니다.
   - 강사 화면에서 [다음 질문]을 누르며 참가자 화면이 실시간으로 바뀌는지 확인합니다.
3. **세션 초기화**:
   - 강연 시작 5분 전, 강사 화면 상단의 **[🔄 (초기화)]** 버튼을 누릅니다.
   - 질문 리스트는 그대로 남고, 테스트했던 응답만 0명으로 깨끗하게 비워집니다.
4. **강의 진행**:
   - 대형 스크린에 `presenter.html`을 띄우고 QR 코드를 안내합니다.
   - 참여자 수가 올라가면 [결과 공개]를 누르고, 질문 강평 후 [다음 질문]으로 넘어가며 몰입도 높은 강의를 진행합니다!
