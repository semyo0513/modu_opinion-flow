# 🌟 OpinionFlow - 연수 강의용 실시간 의견수렴 & 한국어 텍스트마이닝 플랫폼

> **Mentimeter**나 **Slido**처럼 간편하고, 한국어 형태소 정제 엔진과 인터랙티브 시각화를 탑재한 무과금·초경량 웹 플랫폼입니다.  
> 별도의 유료 서버 없이 **GitHub Pages** 무료 정적 호스팅만으로 배포되며, **Firebase Realtime Database**를 연동하여 0.1초 내 초저지연 실시간 동기화를 지원합니다.

---

## 🎯 주요 핵심 기능

1. **간편한 입장 & 질문 생성**
   - 6자리 난수 입장 코드 자동 생성 및 고해상도 QR 코드 즉시 생성
   - 모바일 접속 시 URL 쿼리 파라미터(`?room=CODE`)로 코드 입력 없이 원클릭 바로 입장
2. **실시간 응답자 수 카운팅 & 블라인드 제어**
   - 참여자가 스마트폰에서 [제출]을 누르는 즉시 대형 스크린의 숫자가 바운스(Bounce) 애니메이션과 함께 카운트업
   - 의견 쏠림 현상을 방지하기 위해 강사가 [결과 공개]를 누르기 전까지 내용은 안전하게 마스킹
3. **카드 그리드 & 대형 스크린 Spotlight Zoom 모달**
   - 반응형 카드 레이아웃으로 전체 의견을 한눈에 파악
   - 특정 카드 클릭 시 화면 중앙으로 스케일업 확대 (대형 스크린용 대형 폰트 지원)
   - 키보드 좌/우 방향키(`←`, `→`) 및 `ESC`로 카드 간 슬라이드 탐색 및 닫기
4. **체계적인 한국어 텍스트마이닝 파이프라인 (`korean-nlp.js`)**
   - **정규화**: 초성(ㅋㅋㅋ, ㅎㅎ, ㅠㅠ) 및 특수문자 제거
   - **조사/어미 분리**: 최장일치 알고리즘 기반 한국어 조사 50종 및 용언 어미 60종 분리
   - **불용어(Stopwords) 필터링**: 연수 상투어, 대명사 제거 및 강사 화면에서 원클릭 제외어 추가/삭제
   - **인터랙티브 워드클라우드 (`Wordcloud2.js`)**: 단어 클릭 시 우측 드로어에서 해당 단어가 포함된 실제 원본 카드 필터링 & 형광펜 하이라이트
   - **Top 15 빈도 가로 막대 차트 (`Chart.js`)**: 출현 건수 정밀 시각화
5. **결과 보관을 위한 엑셀/CSV 다운로드**
   - 한글 엑셀에서도 글자 깨짐이 전혀 없는 **UTF-8 BOM (`\uFEFF`)** 내보내기 지원

## 📂 프로젝트 구조

```text
모두의 의견공유/
├── index.html              # 참여자(연수생) 모바일 친화형 입장 및 의견 제출 화면
├── presenter.html          # 강사용 프리젠테이션 대화면 (QR, 카운트, 카드 뷰, 텍스트마이닝)
├── assets/
│   ├── css/
│   │   └── custom.css      # 글래스모피즘, 바운스 카운터, 확대 모달, 형광펜 스타일
│   └── js/
│       ├── firebase-service.js # Firebase Realtime DB 및 로컬 브로드캐스트 하이브리드 통신
│       ├── korean-nlp.js       # 한국어 최장일치 형태소/조사·어미 분리 및 역색인 엔진
│       ├── presenter-app.js    # 강사 프리젠테이션 제어 (워드클라우드, 차트, 카드 줌)
│       └── participant-app.js  # 참여자 폼 제어 및 축하 폭죽(Confetti) 효과
└── README.md
```

## 🚀 빠른 시작 및 로컬 테스트 (Firebase 없이도 즉시 가능!)

본 프로젝트는 **로컬 브로드캐스트(BroadcastChannel)** 모드를 내장하고 있으므로, Firebase 키 설정 없이도 브라우저 탭 2개로 즉시 테스트할 수 있습니다.

1. 브라우저에서 `presenter.html`을 엽니다. (자동으로 6자리 코드 생성)
2. 다른 탭이나 스마트폰에서 `index.html?room=방코드`를 엽니다.
3. 의견을 작성하고 제출하면, 즉시 `presenter.html`의 숫자가 올라가고 워드클라우드와 카드가 실시간 생성됩니다!
4. 강사 화면 상단의 **[✨]** 버튼을 누르면 7건의 샘플 연수 소감이 즉시 생성되어 텍스트마이닝을 바로 시연해볼 수 있습니다.

## ⚡ Firebase Realtime Database 연동 방법 (원격 연수 시)

다양한 네트워크 환경(각자의 스마트폰 LTE/5G)에서 접속하려면 Firebase Realtime Database를 1회 연결해주세요:

1. [Firebase Console](https://console.firebase.google.com/) 접속 후 새 프로젝트 생성
2. 좌측 메뉴 **빌드 > Realtime Database** 클릭 후 데이터베이스 생성 (위치는 기본값 싱가포르 또는 미국 선택)
3. **규칙(Rules)** 탭에서 다음 규칙을 붙여넣고 [게시]:
   ```json
   {
     "rules": {
       "rooms": {
         "$roomCode": {
           ".read": true,
           ".write": true
         }
       }
     }
   }
   ```
4. **프로젝트 설정(톱니바퀴) > 일반 > 내 앱(웹 `</>`)** 추가 후 생성된 `firebaseConfig` 객체 복사
5. `presenter.html` 우측 상단의 **[⚙️(설정)]** 버튼을 누른 뒤 JSON을 붙여넣고 [저장] 누르면 끝!

## 🌐 GitHub Pages 무료 배포 가이드

1. GitHub에 새 공개 저장소(Public Repository) 생성 (예: `opinion-flow`)
2. 프로젝트 파일 전체를 `main` 브랜치에 푸시(Push)
3. GitHub 저장소의 **Settings > Pages** 메뉴로 이동
4. **Build and deployment > Source**를 `Deploy from a branch`로 설정하고 `main` 브랜치 / `/ (root)` 선택 후 **Save**
5. 1~2분 후 생성되는 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 즉시 전 세계 어디서나 강의에 활용할 수 있습니다.
